## 1. 제품 개요

### 1.1 제품 정의

**ZAKAR**(זָכַר)는 히브리어로 **'기억하다'** 를 뜻하며,  
교회 공동체의 사진·영상·문서를 체계적으로 보관하고 공유하는 **아카이브 플랫폼**입니다.

> 앱 슬로건: **"모든 은혜를 기억합니다"**

### 1.2 버전 히스토리

| 버전 | 일자 | 주요 내용 |
|------|------|---------|
| v1.x | 2026.03~04 | iOS 앱 최초 출시 (App Store 제출 완료) |
| **v2.0** | **2026.05~** | **Android 앱 추가 / AWS 아카이브 연동 / 부서별 권한 관리 (본 문서 대상)** |

## 2. 배경 및 목적

### 2.1 문제 정의

| # | 현재 문제 |
|---|---------|
| 1 | iOS 전용 → Android 사용 동역자 접근 불가 |
| 2 | NAS Mock 서비스 → 실제 파일 저장 기능 부재 |
| 3 | 부서별 파일 접근 권한 분리 불가 → 데이터 혼재 위험 |
| 4 | 접속·다운로드 이력 추적 없음 → 자료 유출 확인 불가 |
| 5 | Google Drive 개인 계정 의존 → 공동체 공유 어려움 |

### 2.2 목표

> 크로스플랫폼(iOS + Android) 전환 + AWS 기반 교회 공용 아카이브 구축으로  
> **은혜의교회 동역자 300명 이상**이 플랫폼 관계없이 사역 자료를 안전하게 보관·공유

### 2.3 현재 vs 목표

| 구분 | 현재 (v1.x) | 목표 (v2.0) |
|------|------------|------------|
| 플랫폼 | iOS 전용 | iOS + Android |
| 아카이브 | NAS Mock (저장 없음) | AWS S3 실제 저장 |
| 권한 관리 | 없음 | 부서별 IAM 권한 분리 |
| 이력 추적 | 없음 | DynamoDB 접근 이력 |
| 스토리지 | Google Drive 개인 계정 | 교회 공용 AWS 서버 |

## 4. 기능 요구사항

### 4.1 기존 유지 기능 (iOS v1.x → v2.0 계승)

| 기능 | 설명 | 상태 |
|------|------|------|
| pHash 유사 사진 감지 | DCT + Hamming Distance로 중복·유사 사진 자동 그룹화 | ✅ 유지 |
| 스와이프 제스처 정리 | 위(삭제) / 아래(즐겨찾기) / 좌우(이동) 스와이프 UI | ✅ 유지 |
| ML 자동 정리 | 사용자 선호도 학습 기반 대표 사진 자동 선택 | ✅ 유지 |
| 휴지통 관리 | 삭제 전 임시 보관, 복원 / 영구삭제 | ✅ 유지 |
| 월별 필터링 | 연도·월 기준 사진 필터 및 정리 | ✅ 유지 |
| 앨범 관리 | 사진을 특정 앨범으로 이동·복사·신규 생성 | ✅ 유지 |
| Firebase 인증 | Google 로그인 + 관리자 승인 시스템 | ✅ 유지 |
| Google Drive 백업 | 개인 구글 드라이브 업로드 | ✅ 유지 |

### 4.2 신규 기능 요구사항

#### FR-01. Android 앱
- iOS 앱과 동일한 핵심 기능 제공 (사진 정리, 아카이브, 인증)
- Android 13 (API 33) 이상 지원
- Kotlin + Jetpack Compose 기반 네이티브 구현
- pHash 알고리즘 Android 포팅 (동일 로직, JVM 순수 Kotlin 구현)
- iOS와 동일한 Firebase 프로젝트 사용 (공용 인증)

#### FR-02. AWS S3 아카이브
- 부서별 폴더 구조로 파일 저장 (송도청 / 미들청 / 이음청 / 또래청)
- 사진(HEIC/JPG), 영상(MP4/MOV), 문서(PDF/DOC/PPT) 업로드 지원
- 업로드 진행률 실시간 표시
- 대용량 파일 멀티파트 업로드 지원 (100MB 이상)
- 업로드 완료 파일 목록 조회

#### FR-03. 부서별 권한 관리
- 부서 폴더별 접근 권한 분리 (다른 부서 폴더 접근 불가)
- 역할별 권한 구분
  - `member` : 읽기만
  - `leader` (간사) : 읽기 + 업로드
  - `admin` : 전체 권한
- 다운로드 허용 여부 사용자별 설정 가능
- ZAKARAdmin에서 부서·권한 설정 UI 제공

#### FR-04. 접근·이력 추적
- 파일 접속 이력 기록 (누가 / 언제 / 어떤 파일)
- 다운로드 이력 별도 기록
- 관리자 이력 조회 화면 제공 (ZAKARAdmin)
- 이력 데이터 CSV 내보내기

## 6. 핵심 사용자 스토리

| No | 역할 | 스토리 | 완료 기준 |
|----|------|--------|---------|
| US-01 | Android 동역자 | Android 폰으로 ZAKAR 앱을 설치하고 사용하고 싶다 | Play Store 설치 → Google 로그인 → 사진 정리 완료 |
| US-02 | 일반 동역자 | 행사 사진을 부서 폴더에 업로드하고 싶다 | 부서 선택 → 행사명 입력 → 업로드 완료 확인 |
| US-03 | 일반 동역자 | 내 부서 사진만 볼 수 있었으면 좋겠다 | 타 부서 폴더 접근 시 권한 오류 표시 |
| US-04 | 부서 간사 | 동역자가 파일을 다운로드하는 것을 제어하고 싶다 | 읽기 전용 설정 시 다운로드 버튼 비활성화 |
| US-05 | 관리자 | 누가 언제 어떤 파일을 열었는지 확인하고 싶다 | ZAKARAdmin 이력 탭에서 날짜 / 사용자별 조회 |
| US-06 | Android 동역자 | 유사 사진을 Android에서도 빠르게 정리하고 싶다 | pHash 분석 후 스와이프 정리 완료 |
